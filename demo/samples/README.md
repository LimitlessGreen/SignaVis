# Demo Samples

Enthaltene Test-Audiodateien:

- `signavis-demo.wav` (12 s, 48 kHz, synthetisch) – Demoaufnahme der App. „SignaVis by LimitlessGreen“ ist als
  Schrift ins Spektrogramm geschrieben, dazu synthetische Vogelrufe, ein exponentieller Sweep,
  FM-Synthese, ein Obertonstapel und eine sinc-Kurve. Erzeugt mit
  `uv run --with numpy --with pillow scripts/demo-sample/make_demo_sample.py`.
- `birdsong.wav` (8s Ausschnitt aus `example/soundscape.wav`)
- `tones-1k.wav` (1 kHz Sinus, 5s)
- `sweep-200-8000.wav` (linearer Sweep, 8s)
