---
<video class="shot" src="/SignaVis/media/labeling.mp4" autoplay muted loop playsinline></video>

<ol class="steps-m3">
  <li>**⇧ + drag** to draw a box around the call.</li>
  <li>Enter the species and confirm with **Enter**.</li>
  <li>Drag the corners to refine the box.</li>
</ol>

:::tip
Keys **1–9** assign the most frequently used species. **Ctrl + Z** undoes the last step.
:::
