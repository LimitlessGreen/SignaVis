---
title: Analyse a recording
description: "Identify the bird species on a recording: load audio into SignaVis, inspect the spectrogram and run BirdNET. In the default local mode, no audio is uploaded."
sidebar: { order: 1 }
---
<img class="shot" src="/SignaVis/media/app-desktop.png" alt="Spectrogram of a Tree Pipit song in SignaVis" />

<ol class="steps-m3">
  <li>Drag the audio file into the window.</li>
  <li>Open **Analyse** and start the analysis.</li>
  <li>Review the suggested species.</li>
</ol>

:::note
In the default **local** mode, audio is processed on the device and not uploaded. If a **server**, **cloud** or **hybrid** analysis endpoint is configured, the samples are sent to that endpoint.
:::
