---
title: Regional species lists
description: "Restrict BirdNET results to the species expected at a site: create species lists from the area model, from existing labels or from a file, and export them in BirdNET format."
sidebar: { order: 4 }
---
<img class="shot" src="/SignaVis/media/species-lists.png" alt="Species panel with the options for a new species list" style="max-width: 300px; margin-inline: auto;" />

<ol class="steps-m3">
  <li>Open **Species** and choose **New list**.</li>
  <li>Select a source.</li>
  <li>Activate the list. BirdNET then reports only species on it.</li>
</ol>

| Source | Content |
|---|---|
| Expected here | Area model for the recording's location and week |
| From my labels | All species labelled in the project |
| Import file | BirdNET species list (.txt) or CSV |
| Empty list | Species added individually |

:::note
Lists can be exported in BirdNET's species-list format.
:::
