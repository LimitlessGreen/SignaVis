title: Similar-call search
description: "Find all occurrences of a reference call in a recording: annotate one call, press F and review the suggestions one by one. Nothing is accepted automatically."
sidebar: { order: 5 }
---
<img class="shot" src="/SignaVis/media/similar-calls.png" alt="Review bar with suggestions similar to an annotated Tree Pipit element" />

<ol class="steps-m3">
  <li>Annotate one call and select it.</li>
  <li>Press **F**. Similar calls appear as dotted suggestions.</li>
  <li>Review each suggestion in the bar.</li>
</ol>

| Action | Key |
|---|---|
| Accept | Enter |
| Reject | X |
| Accept all above the score threshold | ⇧ + Enter |

:::tip
Corrections to a suggestion's box carry over to the suggestions not yet reviewed, and each decision re-ranks the rest.
:::
