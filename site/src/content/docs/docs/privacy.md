## Web analytics (Umami)

A self-hosted instance of [Umami](https://umami.is) (stats.sommertheater-altrossthal.de) collects anonymous usage statistics: page views, referrer, browser, operating system, device type and country. In addition, clicks on the following links are counted:

- downloads of the desktop app (file name, version, platform),
- links into the web app,
- links to external sites (target address).

Umami sets no cookies, does not store IP addresses and does not track visitors across websites. The data stays on our server and is not shared with third parties. If the browser sends a “Do Not Track” signal, no statistics are collected. Legal basis: Art. 6(1)(f) GDPR (legitimate interest in understanding how the site is used and improving it).

## Download page (GitHub API)

The download page asks the GitHub API (api.github.com) for the latest release so that links and version are current. The browser connects directly to GitHub, which receives the IP address and technical request data. Legal basis: Art. 6(1)(f) GDPR.
