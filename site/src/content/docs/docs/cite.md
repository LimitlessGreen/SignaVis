If SignaVis helped your research, please cite it. Every release is archived on Zenodo.

- **DOI (all versions):** [10.5281/zenodo.23949899](https://doi.org/10.5281/zenodo.23949899) resolves to the latest version.
- **Specific version:** open the DOI on Zenodo, pick the version you used under "Versions" and cite its own DOI.

## APA

Behrisch, J. (2026). *SignaVis: Interactive waveform + spectrogram audio player for bioacoustic analysis and annotation* [Computer software]. Zenodo. https://doi.org/10.5281/zenodo.23949899

## BibTeX

```bibtex
@software{behrisch_signavis,
  author    = {Behrisch, Jairus},
  title     = {{SignaVis}: Interactive waveform + spectrogram audio player for bioacoustic analysis and annotation},
  year      = {2026},
  publisher = {Zenodo},
  doi       = {10.5281/zenodo.23949899},
  url       = {https://doi.org/10.5281/zenodo.23949899},
  license   = {AGPL-3.0-only}
}
```

## Machine-readable

The repository contains a [CITATION.cff](https://github.com/LimitlessGreen/SignaVis/blob/main/CITATION.cff). GitHub turns it into the **Cite this repository** button, and reference managers such as Zotero can import it.

Please also cite the models you used for analysis (for example BirdNET or BirdBox) as their authors ask.
