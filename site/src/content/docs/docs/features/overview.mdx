The strip below the spectrogram shows the entire recording. The highlighted window marks the visible section; drag it or its handles to move or resize the view.

| Action | Input |
|---|---|
| Scroll in time | Mouse wheel |
| Zoom in time | Ctrl + wheel, or **Time −/+** |
| Zoom in frequency | ⇧ + wheel, or **Freq −/+** |
| Show the whole recording | **Fit** |
| Play / pause | Space |

## Long recordings

<img class="shot" src="/SignaVis/media/overview-long.png" alt="One-hour recording with overview strip and an additional detail strip" />

When the visible window becomes too narrow in the overview, a second detail strip appears below it, showing the surroundings of the current view.
