<ol class="steps-m3">
  <li>Select **Zoom** in the toolbar.</li>
  <li>Drag a region in the spectrogram. Time and frequency zoom to it together.</li>
  <li>Repeat to go further down to individual elements.</li>
</ol>

:::tip
Each right-click returns to the previous view.
:::
