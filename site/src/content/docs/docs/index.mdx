## Brauche ich Vorwissen?

Nein. Du musst weder programmieren können noch wissen, wie ein Spektrogramm berechnet wird. Ein Spektrogramm ist einfach ein Bild deiner Aufnahme: **links nach rechts** läuft die Zeit, **unten nach oben** steigt die Tonhöhe. Je heller eine Stelle, desto lauter.
