```bash
pip install "signavis[widget]"
```

## Show a recording

```python
from signavis import Player

Player("bird.wav", viewMode="spectrogram")
```

Return it from a cell, as with a matplotlib figure.

## Labels in both directions

```python
from signavis import AudioWorkbenchWidget

w = AudioWorkbenchWidget("bird.wav")
w.set_annotations([{"start": 1.0, "end": 2.0, "species": "Turdus merula"}])
w
```

Labels you draw in the player end up in `w.annotations`.

## Your own spectrogram

```python
Player("bird.wav", spectrogram_data=spec)   # 2D float32, frames × mels
```

Or pass a finished image as `spectrogram_image` (PNG bytes, matplotlib figure, PIL image).
