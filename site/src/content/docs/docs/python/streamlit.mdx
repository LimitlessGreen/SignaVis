title: Streamlit
description: "Embed the SignaVis spectrogram player in a Streamlit app: upload a recording and show it with play, zoom and labels."
sidebar: { order: 2 }
---
```bash
pip install "signavis[streamlit]"
```

```python
import streamlit as st
import streamlit.components.v1 as components
from signavis import render_daw_player

f = st.file_uploader("Recording", type=["wav", "mp3", "ogg", "flac"])
if f:
    components.html(render_daw_player(f.read(), viewMode="spectrogram"), height=640)
```
