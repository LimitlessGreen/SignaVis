sidebar: { order: 4 }
---
<img class="shot" src="/SignaVis/media/species-lists.png" alt="Species-Bereich mit den Optionen für eine neue Artenliste" style="max-width: 300px; margin-inline: auto;" />

<ol class="steps-m3">
  <li>**Species** öffnen und **New list** wählen.</li>
  <li>Quelle auswählen.</li>
  <li>Liste aktivieren. BirdNET meldet dann nur noch Arten dieser Liste.</li>
</ol>

| Quelle | Inhalt |
|---|---|
| Expected here | Gebietsmodell für Ort und Woche der Aufnahme |
| From my labels | Alle im Projekt annotierten Arten |
| Import file | BirdNET-Artenliste (.txt) oder CSV |
| Empty list | Arten werden einzeln ergänzt |

:::note
Listen lassen sich im Artenlisten-Format von BirdNET exportieren.
:::
