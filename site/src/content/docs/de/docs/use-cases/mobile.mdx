<img class="shot" src="/SignaVis/media/app-mobile.png" alt="SignaVis auf dem Smartphone: Spektrogramm mit erkannten Arten" style="max-width: 320px; margin-inline: auto;" />

<ol class="steps-m3">
  <li>SignaVis auf dem Smartphone öffnen.</li>
  <li>Unter **Recordings** eine XC-Nummer oder URL eingeben und **Load** antippen.</li>
  <li>**Analyse with BirdNET** antippen.</li>
</ol>

Die erkannten Arten erscheinen als Karten unter dem Player und als Balken über dem Spektrogramm.
