sidebar: { order: 2 }
---
<video class="shot" src="/SignaVis/media/labeling.mp4" autoplay muted loop playsinline></video>

<ol class="steps-m3">
  <li>Mit **⇧ + Ziehen** einen Rahmen um den Ruf legen.</li>
  <li>Art eingeben und mit **Enter** bestätigen.</li>
  <li>Rahmen über die Ecken anpassen.</li>
</ol>

:::tip
Die Tasten **1–9** vergeben die am häufigsten genutzten Arten. **Strg + Z** macht den letzten Schritt rückgängig.
:::
