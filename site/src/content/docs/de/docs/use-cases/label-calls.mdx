---
<video class="shot" src="/SignaVis/media/labeling.mp4" autoplay muted loop playsinline controls></video>

<ol class="steps-m3">
  <li>Mit **⇧ + Ziehen** einen Rahmen um den Ruf legen.</li>
  <li>Art eingeben und mit **Enter** bestätigen.</li>
  <li>Rahmen über die Ecken anpassen.</li>
</ol>

:::tip
Bei ausgewählter Annotation setzen die Tasten **1–7** den Ruftyp (song, call, alarm call …). **Strg + Z** macht den letzten Schritt rückgängig.
:::
