---
title: Suche nach ähnlichen Rufen
description: "Alle Vorkommen eines Referenzrufs in einer Aufnahme finden: einen Ruf annotieren, F drücken und die Vorschläge einzeln prüfen. Nichts wird automatisch übernommen."
sidebar: { order: 5 }
---
<img class="shot" src="/SignaVis/media/similar-calls.png" alt="Durchsichtsleiste mit Vorschlägen, die einem annotierten Baumpieper-Element ähneln" />

<ol class="steps-m3">
  <li>Einen Ruf annotieren und auswählen.</li>
  <li>**F** drücken. Ähnliche Rufe erscheinen als gepunktete Vorschläge.</li>
  <li>Vorschläge in der Leiste einzeln prüfen.</li>
</ol>

| Aktion | Taste |
|---|---|
| Übernehmen | Enter |
| Verwerfen | X |
| Alle über der Score-Schwelle übernehmen | ⇧ + Enter |

:::tip
Korrekturen am Rahmen eines Vorschlags werden auf die noch nicht geprüften Vorschläge übertragen; jede Entscheidung sortiert die übrigen neu.
:::
