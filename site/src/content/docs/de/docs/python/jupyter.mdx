## Aufnahme anzeigen

```python
from signavis import Player

Player("vogel.wav", viewMode="spectrogram")
```

Die Anzeige erfolgt, wenn das Objekt als letzte Zeile einer Zelle steht – wie bei einer matplotlib-Grafik.

## Annotationen in beide Richtungen

```python
from signavis import AudioWorkbenchWidget

w = AudioWorkbenchWidget("vogel.wav")
w.set_annotations([{"start": 1.0, "end": 2.0, "species": "Turdus merula"}])
w
```

Im Player gezeichnete Annotationen stehen in `w.annotations` zur Verfügung.

## Eigene Spektrogramme

```python
Player("vogel.wav", spectrogram_data=spec)   # 2D float32, Frames × Mels
```

Alternativ lässt sich ein fertiges Bild als `spectrogram_image` übergeben (PNG-Bytes, matplotlib-Figur, PIL-Bild).
