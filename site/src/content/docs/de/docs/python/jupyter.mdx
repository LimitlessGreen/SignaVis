```bash
pip install "signavis[widget]"
```

## Aufnahme zeigen

```python
from signavis import Player

Player("vogel.wav", viewMode="spectrogram")
```

Als letzte Zeile einer Zelle zurückgeben, wie eine matplotlib-Grafik.

## Labels in beide Richtungen

```python
from signavis import AudioWorkbenchWidget

w = AudioWorkbenchWidget("vogel.wav")
w.set_annotations([{"start": 1.0, "end": 2.0, "species": "Turdus merula"}])
w
```

Im Player gezeichnete Labels landen in `w.annotations`.

## Eigenes Spektrogramm

```python
Player("vogel.wav", spectrogram_data=spec)   # 2D float32, Frames × Mels
```

Oder ein fertiges Bild als `spectrogram_image` (PNG-Bytes, matplotlib-Figur, PIL-Bild).
