sidebar: { order: 3 }
---
```bash
pip install "signavis[gradio]"
```

```python
import gradio as gr
from signavis.gradio import SignaVisPlayer, player_value

with gr.Blocks() as demo:
    player = SignaVisPlayer()
    gr.Button("Zeigen").click(
        lambda: player_value(
            "vogel.wav",
            detections=[{"start": 3, "end": 6, "label": "Turdus merula", "confidence": 0.91}],
            select=(3, 6),  # hinspringen und abspielen
        ),
        outputs=player,
    )

demo.launch()
```

<img class="shot" src="/SignaVis/media/python-gradio.png" alt="Gradio-App mit SignaVis-Player und einer Erkennung" />

- Erkennungen werden in der Tabelle und im Spektrogramm angezeigt.
- Audio wird vom Datenträger gestreamt; auch mehrstündige Dateien sind möglich.
- Keine Internetverbindung erforderlich; alle Ressourcen sind im Paket enthalten.
