```bash
pip install "signavis[gradio]"
```

```python
import gradio as gr
from signavis.gradio import SignaVisPlayer, player_value

with gr.Blocks() as demo:
    player = SignaVisPlayer()
    gr.Button("Zeigen").click(
        lambda: player_value(
            "vogel.wav",
            detections=[{"start": 3, "end": 6, "label": "Turdus merula", "confidence": 0.91}],
            select=(3, 6),  # hinspringen und abspielen
        ),
        outputs=player,
    )

demo.launch()
```

- Erkennungen erscheinen in der Tabelle und im Spektrogramm.
- Die Audiodatei wird von der Platte gestreamt, auch stundenlange Dateien gehen.
- Kein Internet nötig, alles steckt im Paket.
