Der Balken unter dem Spektrogramm zeigt die gesamte Aufnahme. Das hervorgehobene Fenster markiert den sichtbaren Ausschnitt; durch Ziehen am Fenster oder an seinen Griffen lässt sich die Ansicht verschieben oder in der Größe ändern.

| Aktion | Eingabe |
|---|---|
| In der Zeit scrollen | Mausrad |
| Zeitzoom | Strg + Mausrad oder **Time −/+** |
| Frequenzzoom | ⇧ + Mausrad oder **Freq −/+** |
| Ganze Aufnahme anzeigen | **Fit** |
| Wiedergabe / Pause | Leertaste |

## Lange Aufnahmen

<img class="shot" src="/SignaVis/media/overview-long.png" alt="Einstündige Aufnahme mit Übersichtsbalken und zusätzlichem Detail-Streifen" />

Wird das sichtbare Fenster in der Übersicht zu schmal, erscheint darunter ein zweiter Detail-Streifen mit der Umgebung der aktuellen Ansicht.
