<video class="shot" src="/SignaVis/media/magnifier.mp4" autoplay muted loop playsinline></video>

<ol class="steps-m3">
  <li>**Zoom** in der Werkzeugleiste wählen.</li>
  <li>Im Spektrogramm einen Bereich aufziehen. Zeit und Frequenz werden gemeinsam darauf vergrößert.</li>
  <li>Wiederholen, um bis auf einzelne Elemente hineinzugehen.</li>
</ol>

:::tip
Jeder Rechtsklick kehrt zur vorigen Ansicht zurück.
:::
