Wenn SignaVis bei deiner Forschung geholfen hat, zitiere es bitte. Jedes Release wird auf Zenodo archiviert.

- **DOI (alle Versionen):** [10.5281/zenodo.23949899](https://doi.org/10.5281/zenodo.23949899) führt immer zur neuesten Version.
- **Bestimmte Version:** DOI auf Zenodo öffnen, unter „Versions“ die verwendete Version wählen und deren eigene DOI angeben.

## APA

Behrisch, J. (2026). *SignaVis: Interactive waveform + spectrogram audio player for bioacoustic analysis and annotation* [Computer software]. Zenodo. https://doi.org/10.5281/zenodo.23949899

## Maschinenlesbar

Im Repository liegt eine [CITATION.cff](https://github.com/LimitlessGreen/SignaVis/blob/main/CITATION.cff). GitHub macht daraus den Button **Cite this repository**, Literaturverwaltungen wie Zotero können sie importieren.

Bitte zitiere zusätzlich die Modelle, die du zur Auswertung genutzt hast (z. B. BirdNET oder BirdBox), so wie deren Autoren es angeben.
